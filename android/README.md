# برنامه‌ی اندروید راننده

پوسته‌ای دور همان پنل راننده‌ی `sedo.site/queue`. کدِ صفحه‌ها یکی است —
هر تغییری روی سرور، بلافاصله در برنامه هم دیده می‌شود و نیازی به نسخه‌ی
تازه‌ی APK نیست.

## چرا WebView و نه TWA یا Capacitor

**TWA** به نصب‌بودنِ Chrome وابسته است. روی گوشیِ راننده‌ای که سالی یک بار
به‌روزرسانی می‌شود، این فرض خطرناکی است؛ اگر Chrome نباشد یا قدیمی باشد،
برنامه به یک تب مرورگر تبدیل می‌شود.

**Capacitor** یک زنجیره‌ی ابزار کامل و صدها مگابایت وابستگی می‌آورد، برای
قابلیت‌هایی که پنل راننده اصلاً لازم ندارد: نه دوربین، نه GPS، نه فایل.
راننده فقط صفحه می‌بیند و QR نشان می‌دهد.

پس همان چند رفتاری که واقعاً لازم است دستی نوشته شده — حدود ۱۵۰ خط Kotlin.

## گرفتن APK بدون نصب هیچ چیزی

گیت‌هاب خودش APK را می‌سازد (`.github/workflows/android.yml`). لازم نیست
Android Studio یا SDK روی کامپیوترتان باشد.

**دانلود مستقیم — از داخل ایران باز است:**

<https://raw.githubusercontent.com/ferya3/nobatdehi/apk/nobatdehi-driver.apk>

⚠️ بخش **Artifacts** در صفحه‌ی Actions را فراموش کنید: فایلش از
`blob.core.windows.net` سرو می‌شود و از ایران دانلود نمی‌شود. شاخه‌ی `apk`
دقیقاً برای همین ساخته شده.

**گذاشتنش روی سرور، تا راننده‌ها هم بتوانند بگیرند** — آن‌ها هم به
گیت‌هاب دسترسی ندارند:

```bash
cd /var/www/nobatdehi
sudo -u nobatdehi curl -fsSL -o public/nobatdehi-driver.apk \
  https://raw.githubusercontent.com/ferya3/nobatdehi/apk/nobatdehi-driver.apk
```

بعد از آن آدرس دانلود برای راننده‌ها این است:
`https://sedo.site/nobatdehi-driver.apk`

## ساخت روی ویندوز — ساده‌ترین راه

`build-apk.sh` یک اسکریپت لینوکسی است و در Command Prompt ویندوز اجرا
نمی‌شود. روی ویندوز از **Android Studio** استفاده کنید؛ خودش Java و
Android SDK را می‌آورد و لازم نیست چیزی دستی نصب کنید.

۱. Android Studio را نصب کنید: <https://developer.android.com/studio>
   (⚠️ این آدرس از داخل ایران مسدود است — با تحریم‌شکن دانلود کنید.)

۲. در Android Studio: **Open** و پوشه‌ی `android` را انتخاب کنید — نه کل
   پروژه، فقط همین پوشه.

۳. اولین بار چند دقیقه طول می‌کشد تا وابستگی‌ها را بگیرد. اگر گیر کرد،
   احتمالاً تحریم‌شکن روشن نیست.

۴. حالا بسازید. **مطمئن‌ترین راه، ترمینالِ خودِ Android Studio است** —
   چون به اسم منو کار ندارد و از Java و SDK خودِ Android Studio استفاده
   می‌کند:

   **View ← Tool Windows ← Terminal** (یا `Alt`+`F12`)، بعد:

   ```
   gradlew.bat assembleDebug
   ```

   اگر ترجیح می‌دهید از منو بزنید، جای گزینه بین نسخه‌ها فرق دارد:

   | نسخه‌ی Android Studio | مسیر منو |
   |---|---|
   | Ladybug (۲۰۲۴.۲) و جدیدتر | **Build ← Generate App Bundles or APKs ← Generate APKs** |
   | قدیمی‌تر | **Build ← Build Bundle(s) / APK(s) ← Build APK(s)** |

   اگر منوی Build تقریباً خالی است، یعنی Gradle sync هنوز تمام نشده یا
   خطا خورده — تا آن موفق نشود این گزینه‌ها ساخته نمی‌شوند.

۵. خروجی اینجاست:

```
android\app\build\outputs\apk\debug\app-debug.apk
```

همین فایل را روی گوشی کپی کنید و نصب شود.

### یا از خط فرمان ویندوز

اگر Java 17+ و Android SDK را از قبل دارید، در **Command Prompt** (نه
PowerShell) داخل پوشه‌ی `android`:

```
gradlew.bat assembleDebug
```

نقطه‌اسلش (`./`) نگذارید — آن نوشتار لینوکس است و ویندوز آن را نمی‌شناسد.

## ساخت روی لینوکس

```bash
cd android
./build-apk.sh
```

بار اول Android SDK را دانلود می‌کند (حدود ۱۵۰ مگابایت).

⚠️ آدرس `dl.google.com` از داخل ایران معمولاً مسدود است. یا با تحریم‌شکن
اجرا کنید، یا SDK را یک بار جای دیگری بگیرید و `ANDROID_HOME` را به آن
اشاره دهید.

خروجی: `android/nobatdehi-driver.apk`

## اعلان روی گوشی راننده

مدیر از `/panel/notifications` پیام می‌فرستد و برنامه آن را روی نوار اعلان
نشان می‌دهد.

⚠️ **این کانال فوری نیست.** اندروید اجازه‌ی کار دوره‌ای زیر ۱۵ دقیقه
نمی‌دهد و زیر Doze حتی دیرتر اجرا می‌کند. راهِ push واقعی، Firebase است که
از ایران نه ثبت‌نامش ممکن است و نه روی گوشیِ بدون سرویس‌های گوگل کار
می‌کند. پس:

| خبر | کانال |
|---|---|
| «نوبت شما فرا رسید» | پیامک — فوری، روی هر گوشی‌ای |
| «نوبت جلویی شروع شد» | پیامک **و** اعلان |
| «فردا تعطیل است» | اعلان — رایگان و بدون محدودیت طول |

روی اندروید ۱۳ به بعد، بار اول که برنامه باز شود مجوز اعلان پرسیده
می‌شود. اگر راننده رد کند، بقیه‌ی برنامه دست‌نخورده کار می‌کند.

## کلید امضا

بدون کلید، خروجی `debug` است — روی گوشی نصب می‌شود ولی برای انتشار مناسب
نیست و **پیوند لینک هم کار نمی‌کند**.

```bash
cd android
keytool -genkeypair -v -keystore nobat.keystore \
  -alias nobat -keyalg RSA -keysize 2048 -validity 10000

cat > keystore.properties <<'EOF'
storeFile=nobat.keystore
storePassword=<رمز>
keyAlias=nobat
keyPassword=<رمز>
EOF
```

⚠️ **این دو فایل را گم نکنید و در گیت نگذارید.** اندروید فقط نسخه‌ای را
به‌روزرسانی می‌داند که با همان کلید امضا شده باشد؛ با کلید تازه، راننده‌ها
باید برنامه را حذف و دوباره نصب کنند.

## پیوند لینکِ پیامک به برنامه

راننده پیامکِ نوبت می‌گیرد. اگر لینکش مرورگر را باز کند، باید دوباره وارد
شود. برای اینکه مستقیم داخل برنامه باز شود:

۱. بعد از ساخت با کلید، اسکریپت اثر انگشت را چاپ می‌کند.
۲. آن را در `.env` سرور بگذارید:

```
ANDROID_FINGERPRINTS=A1:B2:C3:...
```

۳. `php artisan config:cache` و ری‌استارت PHP-FPM.

بررسی:

```bash
curl -s https://sedo.site/.well-known/assetlinks.json
```

باید بسته‌ی `ir.nobatdehi.driver` و همان اثر انگشت را نشان دهد.

## تغییر دامنه

فقط `gradle.properties`:

```
NOBAT_URL=https://example.ir
NOBAT_HOST=example.ir
```

و دوباره بسازید. آدرس در کد تکرار نشده — از همین‌جا به Kotlin و به
AndroidManifest می‌رود.

## انتشار

فروشگاه Google Play از ایران در دسترس نیست. گزینه‌ها:

- **بازار / مایکت** — همان APK امضاشده را آپلود کنید.
- **دانلود مستقیم** — فایل را روی سرور بگذارید و لینکش را به راننده‌ها
  پیامک کنید. اندروید هشدار «منبع ناشناس» می‌دهد که یک بار باید تأیید شود.

## هر بار انتشار نسخه‌ی تازه

`versionCode` باید بالا برود، وگرنه اندروید نصب را رد می‌کند:

```
NOBAT_VERSION_CODE=2
NOBAT_VERSION_NAME=1.0.1
```

ولی برای تغییرِ خودِ صفحه‌ها لازم نیست — آن‌ها از سرور می‌آیند.
